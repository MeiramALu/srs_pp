# SIW 2 — сравнение OpenMP и MPI

Эксперимент: одномерное уравнение теплопроводности в трёх реализациях (OpenMP, MPI, MPI+OpenMP).

- `SIW2_Report_OpenMP_vs_MPI.docx` — отчёт (Word)
- `SIW2_Presentation.pptx` — презентация для защиты
- `SIW2_Explanation_RU.md` — подробное объяснение задачи, результатов и подсказки к защите
- `src/`, `scripts/`, `results/`, `figures/` — код, скрипты запуска, сырые данные, графики

Подробности и инструкция по воспроизведению — в `SIW2_Explanation_RU.md`.
